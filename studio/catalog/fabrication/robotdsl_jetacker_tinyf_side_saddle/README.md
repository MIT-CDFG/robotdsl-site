# JetAcker left TinyF side saddle

The saddle seats on the original left side wall. The two selected bore centers are 16 mm apart vertically. The side wall is 1.5 mm thick. M3 screws are intentional; no host thread or new drilling is claimed. Install the host screws, washers on both wall faces and separate nuts before installing the sensor. Remove the upper deck if required for inside nut access; do not assume omitted electronics or wires are absent on a real kit.

The TinyF ears run vertically, 30 mm apart, with the socket toward the rear. Use the native ears and separate M2 x 8 screws, 0.3 mm washers and nuts. Install the sensor after tightening the host bolts, because its body covers their forward tool path. The lens looks left (+Y), within the original wheel width. Preserve the original front camera, LiDAR, motors and wheels. Continuous motion and physical assembly have not been qualified.

## Fabrication and limitations

Print only the listed polymer pieces, using PA12 SLS as the design process. Use separate metal hardware; do not print screws or nuts. Nominal bores and dimensions require a real fit check. No strength, creep, vibration, preload or weather qualification has been performed. Electrical integration, OS/driver, calibration and initial operation are outside this fixture.
