==============================================================================

This app distributes two files of the npm package onnxruntime-web 1.30.0:
dist/ort-wasm-simd-threaded.wasm, ONNX Runtime's WebAssembly build with SIMD
and threads (without JSEP, WebGPU, WebNN or XNNPACK), and
dist/ort.wasm.bundle.min.mjs, the JavaScript of onnxruntime-web and
onnxruntime-common with the loader that Emscripten generated for that
WebAssembly build. The package was built from ONNX Runtime tag v1.30.0 with
Emscripten 4.0.23; the build string in the wasm reads
"git-commit-id=f2c39fe2f". ort-wasm-simd-threaded.wasm contains ONNX Runtime
(component 1), the libraries that ONNX Runtime's build compiles into it
(components 2 to 13) and the C and C++ runtime libraries of Emscripten
(components 14 to 19). ort.wasm.bundle.min.mjs contains the JavaScript of
onnxruntime-web and onnxruntime-common (component 1) and the JavaScript
runtime that Emscripten generates (component 14).

The build options were those of the release build in ONNX Runtime's npm
packaging pipeline at that tag
(tools/ci_build/github/azure-pipelines/templates/web-ci.yml and
linux-wasm-ci.yml): --build_wasm --enable_wasm_simd --enable_wasm_threads
--enable_wasm_api_exception_catching --disable_rtti --target
onnxruntime_webassembly. The paths recorded in the wasm
(/mnt/azure_nvme_temp/_work/1/s for the sources,
.../_work/1/b/wasm_inferencing/Release for the build) fit that pipeline.
With these options ONNX Runtime's build compiles none of the other libraries
in its cmake/deps.txt into the wasm (among them cpuinfo, XNNPACK,
pthreadpool, mimalloc, KleidiAI, Dawn and the telemetry libraries).
