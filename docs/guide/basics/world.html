The world ​

The .world file declares where the robot starts, what surrounds it, and the places the task refers to.

robotdsl
World demo {
    physics(gravity = (0, 0, -9.81))
    spawn(robot = @core/diff_bot, pose = (0, 0, 0.05, 0, 0, 0, 1))
    Scenario room(ref = "empty", ground_plane = true) {
        Obstacle box(type = "box", pos = (1.2, 0, 0.25, 0, 0, 0, 1), size = (0.3, 0.3, 0.5))
        Marker flag(type = "cylinder", pos = (2.5, 0, 0.01, 0, 0, 0, 1), size = (0.3, 0.3, 0.02))
    }
    Goal goal(pose = (2.5, 0, 0, 0, 0, 0, 1))
}

Poses ​

A pose is seven numbers, a position and a quaternion: (x, y, z, qx, qy, qz, qw). No rotation is (x, y, z, 0, 0, 0, 1). Lengths are metres.

Physics and spawn ​

physics(gravity = (x, y, z)) sets gravity in m/s². Without it, the targets use standard gravity, (0, 0, -9.81).

spawn places the robot the .core file declares:

robotdsl
spawn(robot = @core/diff_bot, pose = (0, 0, 0.05, 0, 0, 0, 1))

Scenarios and entities ​

A scenario groups the things in one environment. Its ref is the base environment; "empty" is the only one the targets build today, so the room is whatever the scenario's entities make it. ground_plane = true adds a floor, and without one the robot falls.

Each entity has a type, a name, a shape and a pose:

Entity typeIs
ObstacleSomething the robot must not touch. Touching one fails the run's physical verdict.
SupportSurfaceA floor, ramp or pad the robot drives on; contact is expected.
MarkerA visual mark, such as a goal disc. It has no collision unless collision = true.

The shape is a type of "box", "sphere" or "cylinder" with a size of (x, y, z) in metres; a sphere's diameter and a cylinder's are the x size, a cylinder's height the z size.

Entities stay where they are placed. Leave is_static out, or write is_static = true; an entity declared movable is refused, because an entity states no mass to move it with.

Obstacles are drawn into the navigation map, seen by the robot's sensors, and measured against when a run is judged.

Goals ​

A goal is a named place the task can drive to, given by a pose or by an entity as target:

robotdsl
Goal goal(pose = (2.5, 0, 0, 0, 0, 0, 1))
Goal at_flag(target = @world/flag)

The task refers to it as @world/goal.
