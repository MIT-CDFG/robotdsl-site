Validation rules ​

This page is generated from mobiledsl.validation.standard; edit the code, not the page. Each rule asks one question of the facts analysis derived and answers pass, fail, unknown or not_applicable with the evidence it used. fail is an error that blocks compilation. unknown means the facts do not settle the question, usually because a library part did not state something; it is a warning, never a pass. A rule reads facts; it does not recompute geometry and does not change the program.
